# Gestão Escolar

Projeto foi desenvolvido em Java para que fosse gerenciado as informações escolares.

## Funções

- Cadastro de espaços
- Cadastro de recursos educacionais
- Associação de recursos aos espaços
- Validação dos campos
- Armazenamento temporário em memória
- Interface gráfica com Java Swing

## Estrutura

- `models`: classes do sistema
- `repository`: armazenamento dos dados
- `views`: telas do sistema

## Tecnologias usadas

- Java
- Java Swing
- IntelliJ IDEA

## Como executar

Execute a classe `MenuPrincipal`.

A partir dela é possível acessar:
- Cadastro de Espaço
- Cadastro de Recurso
